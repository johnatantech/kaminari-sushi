# Kaminari Sushi — projeto conceitual

Site de uma página para um rodízio japonês **fictício**, criado como projeto de portfólio.

**Preview:** https://johnatantech.github.io/kaminari-sushi/

## Destaques

- HTML e CSS puros, sem framework nem build
- Layout responsivo (desktop → 360 px), com grade em mosaico no cardápio
- Identidade inspirada na cultura japonesa: numerais 一 二 三, termos em japonês, escrita vertical e padrão seigaiha em SVG
- Navbar fixa com fundo translúcido e rolagem suave entre seções
- Acessibilidade: foco visível no teclado, textos alternativos e respeito a `prefers-reduced-motion`
- Performance: imagens otimizadas com carregamento sob demanda e fonte japonesa carregando só os caracteres usados
- Deploy contínuo no Azure Static Web Apps via GitHub Actions, com preview automático a cada Pull Request

## Rodar localmente

Abra a pasta no VS Code, instale as extensões recomendadas e use **Open with Live Server** em `index.html`.

## Aviso

Kaminari Sushi é uma marca fictícia. Preços, endereço, horários e contatos são ilustrativos. Fotos: Freepik (ver `CREDITOS.md`).
